# Données locales des wilayas et communes

MARKI charge en priorité le fichier :

```text
public/assets/data/algeria-communes.json
```

Ce fichier est installé depuis le projet libre **GeoAlgeria** :

- Projet : `yasserstudio/geoalgeria`
- Paquet utilisé par le script : `geoalgeria@1.1.1`
- Fichier source : `data/ecommerce/communes.json`
- Licence annoncée par le projet : MIT

Le script d'installation télécharge également la licence d'origine dans :

```text
public/assets/data/GEOALGERIA_LICENSE.txt
```

Ne modifiez pas manuellement le fichier JSON. Pour le remettre à jour, relancez :

```powershell
.\tools\scripts\install_algeria_locations.bat
```
